# Xis da Claudinha - App de Delivery

## Instalação rápida

1. Instale Node.js: https://nodejs.org
2. Extraia este ZIP
3. Abra CMD na pasta do projeto
4. Rode:
   ```
   npm install
   npx expo login
   eas build --platform android --profile preview
   ```
